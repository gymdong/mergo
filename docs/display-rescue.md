# 밝기·글자 크기 접근성 복구

## 목표와 범위

어르신이 `도와줘`를 누른 뒤 "화면이 너무 어두워", "글씨가 너무 작아"처럼 말하면, 읽기 어려운 설정 화면으로 보내지 않고 머고가 **밝기 또는 시스템 글자 크기를 직접 올린다**. 가족이 미리 편한 화면 값을 저장하고 자동 복구를 켜 둔 경우에는 급격한 저하를 감지해 저장한 값으로 되돌린다. 글자를 줄이거나 화면을 어둡게 하는 요청, 모호한 "화면이 이상해"는 자동 변경하지 않는다.

## 사용 전 준비

1. 가족이 첫 화면의 **화면 설정 바꾸기** 권한(`WRITE_SETTINGS`)을 허용한다.
2. 가족이 휴대전화 밝기·글자 크기를 편하게 맞추고 머고 설정에서 **지금 밝기·글자 크기 저장**을 누른다.
3. 원할 때만 **화면 밝기·글자 크기 자동 복구**를 켠다. 기본값은 꺼짐이다.

명시적 음성 요청은 저장값·자동 복구 설정이 없어도 권한만 있으면 안전한 한 단계 올리기를 시도한다. 밝기 자동 복구는 휴대전화의 **자동 밝기가 꺼진 수동 모드**에서만 작동한다. 직접 "밝게 해줘", "안 건드렸는데 어두워졌어"라고 하면 자동 밝기를 수동으로 바꾸고 고정 밝기를 적용한다. 저장된 밝기 값이 이미 255여도 자동 밝기가 켜져 있다면 수동 모드 전환을 시도한다. 자동 밝기가 모든 어르신에게 불필요하다고 가정해 설치 시 일괄 해제하지는 않는다.

## 기본 밝기 지킴이

권한만 있으면 기본으로 켜져 있다. 시스템 밝기(1~255)가 **50 밑**이면, 값이 멈춘 뒤 2초를 기다려 **78**로 올린다. 자동 밝기가 켜져 있으면 함께 끈다. 자동 밝기 중에 이 설정값이 실제 화면 밝기를 따라가는지는 기기마다 다를 수 있어 실기기 확인이 필요하다(에뮬레이터는 자동 밝기를 지원하지 않는다). 그다음 "너무 어두워서 밝게 만들었어요. 어때요?"라고 묻고 `좋아`/`싫어`를 받는다. `싫어`면 이 기기에서 자동 밝기(`autoBrightness`)를 끄고 저장값 밝기 복구도 하지 않는다. 밝기는 되돌리지 않으며, 답이 없으면 기능을 그대로 둔다. 다시 켜는 곳은 머고 설정의 **너무 어두우면 자동으로 밝게**다.

요청해서 밝게 한 경우의 완료 확인은 "이 화면이 맞나요?" 대신 "이 밝기 괜찮으세요?"를 쓴다.

## 처리 경로

- `KeywordRules`가 명시적 발화를 인식하면 `MergoBrain`이 LLM 추측 없이 `brighten_screen` 또는 `increase_text_size`를 선택한다. 거꾸로 바꾸라는 말은 제외하고, LLM이 근거 없이 이 레시피를 고르면 차단한다.
- `MergoController`는 `도와줘` 후 다른 문제를 먼저 짐작하더라도 자유 발화를 받아 시각 문제로 전환한다. 민감 화면에서도 **화면 노드를 누르지 않고 시스템 설정만** 바꾼다. 실행 전에 음성 대기로 지연하지 않고, 설정 변경 후 결과를 알린다.
- `AndroidDisplaySettings`가 시스템 설정을 쓰고, `BrightenScreen`·`IncreaseTextSize`가 값을 다시 읽어 확인한다. 확인 실패는 성공으로 기록하지 않는다.
- `DisplayRescueMonitor`는 서비스 시작 시 값만 기억한다. 이후 저장값에 가까운 밝기·글자 크기가 **갑자기 크게 내려간 경우에만** 자동 복구를 요청한다. 저장값이 없거나 선택권·권한이 없으면 실행하지 않는다.

## 한계와 검증

글자 크기 설정값을 올려도 앱이 글꼴 크기를 자체적으로 고정했다면 그 앱의 글자가 실제로 커졌다는 보장은 없다. 자동 감지는 서비스가 실행 중이고 설정 변경 관찰자가 이벤트를 받았을 때 동작한다. 화면 회전·배율, 자동 밝기 상태의 저하, 서비스 시작 전에 이미 낮아진 값은 복구하지 않는다. 다른 도움 대화가 진행 중이면 최대 60초 기다렸다가 현재 값이 여전히 낮은 경우에만 복구한다. 그보다 오래 바쁜 경우나 서비스가 중지된 경우는 놓칠 수 있다.

JVM 단위 테스트는 발화 분기, 권한·쓰기 실패, 설정값 검증, 급락 감지와 시작 시 오탐 방지를 검증한다. 디버그 에뮬레이터에서 밝기·글자 크기 직접 변경 경로를 확인했다. 실제 음성 엔진으로 버튼을 누르는 E2E와 자동 복구 E2E는 별도 기기 검증이 필요하다.
